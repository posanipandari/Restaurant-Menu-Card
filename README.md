🍴 Restaurant Menu Website

A simple and responsive restaurant menu website built using HTML and CSS. This is a beginner-friendly frontend project created to practice webpage structure, styling, cards, Flexbox, buttons, and responsive design.

🚀 Features

- Restaurant header section
- Menu section
- Food item cards
- Food name and description
- Price display
- Order Now buttons
- Hover effects
- Responsive design for mobile devices
- Flexbox layout

🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive Design

📂 Project Structure

project-02-restaurant/
│
├── index.html
├── style.css
└── README.md

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run it in your browser.

📸 Preview

The website contains a restaurant header and menu cards for:

- 🍕 Pizza — ₹199
- 🍔 Burger — ₹149
- 🍝 Pasta — ₹179

🎯 Learning Goals

This project helped me practice:

- HTML page structure
- CSS selectors
- CSS box model
- Flexbox
- Buttons
- Card design
- Hover effects
- Media queries
- Responsive web design
